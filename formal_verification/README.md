# Continuous Formal Verification & SMT Solver Proof Suite

This subsystem houses machine-checked theorem proofs (Lean 4) and SMT constraint solver artifacts (Z3 / SMT-LIB2), operating as an immutable mathematical regression suite.

## The Workflow

```
[Algorithmic Invariant Spec] (Lean 4 / SMT-LIB2)
            │
            ▼
[Automated Constraint Solver] (Z3 / CVC5)
            │
    ┌───────┴────────────────────────┐
    ▼                                ▼
[Proof Certificate Generated]   [Counterexample Isolated]
    │                                │
    ▼                                ▼
Machine-Checked Lemma (.lean)   Minimal Unsat / Sat Trace (.smt2)
    │                                │
    └───────┬────────────────────────┘
            ▼
[Immutable Verification Suite]
            │
            ▼
[Cross-Platform CI Workers Validate Elaboration]
```

## Directory Structure
- `proof_certificates/`: Machine-checked Lean 4 formal certificates establishing correctness, algebraic identities, and algorithmic termination.
- `smt_counterexamples/`: SMT-LIB2 benchmark models and counterexample traces generated by automated solvers during invariant checking.
- `property_invariants/`: High-level algorithmic specification lemmas (sorting permutation stability, array bounds safety, cryptographic constant-time assertions).

## Elaboration & Checking
Verify proof certificates locally using the Lean 4 toolchain:
```bash
lean formal_verification/proof_certificates/AssociativeRingLaws.lean
```

Verify SMT counterexamples via Z3:
```bash
z3 formal_verification/smt_counterexamples/overflow_modulo_inv.smt2
```
