# Lean 4 Formal Algorithms & Mathematics

Formal verification of graph algorithms, arithmetic, and sorting networks in the Lean 4 interactive theorem prover.

## Verified Mathematics

The `math/`, `logic/`, `data_structures/`, `sorting/`, and `graphs/`
directories contain machine-checked Lean 4 developments covering natural
and integer arithmetic, order and divisibility, GCD theory, modular
arithmetic, parity, exponentiation, boolean and propositional logic,
option and tree lemmas, reachability in directed graphs, and insertion
sort length correctness. Every file elaborates with `lean <file>`.
